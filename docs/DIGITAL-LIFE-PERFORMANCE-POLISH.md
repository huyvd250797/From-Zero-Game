# V2.14.0 — Digital Life, Performance & Polish

## Digital life
Use the new Điện thoại HUD shortcut or Menu cuộc đời → Điện thoại. Home includes 15 applications/links. The phone and management panels pause the gameplay clock; opening a management panel stops any active life plan, as before. Wallet uses `personal-finance.transfer`; money is not income or expense and the reserved goal funds cannot be withdrawn. Phone wallet requires leaving transit and dismounting. All loans, term deposits, and investment trades retain their canonical access checks. No remote bypass of bank opening times or location checks.

NPC messages: only known contacts, three fixed topics, one communication per contact per game day. Replies are synthesized locally from schedule, venue and health. No trust/reputation, relationship, XP, money, time or NPC state change. The message history stores both topic and response at the time of communication, not a live external chat. To meet, use the existing route finder. No network or paid AI. New characters start with empty digital history.

Notification center stores up to 80 important/forced notices per character, preserves read state and offers all/unread/warning/life/economy filters. Exact message + game minute deduplication, existing important-event policy and alert transitions retained. Historical major-event journal is still displayed, not converted into fabricated unread notices. Existing saves with no digital property migrate to empty notice/message arrays; validate rejects malformed data. Message history retains 80 conversations. Schema remains 1.

## Save and offline
The recovery application displays validity, character, timestamp and approximate serialized size of primary, rolling backup and checkpoint. A user-confirmed current-state checkpoint uses the existing checkpoint slot, without replacing the primary or backup. The old automatic checkpoint-before-replacement behavior is retained; a subsequent replacement can overwrite that checkpoint, so export JSON for long-term preservation. `persistSave` now rechecks the comparison token immediately before writing and verifies readback. LocalStorage is not an atomic cross-tab transaction: simultaneous writers may still race. Save failure is surfaced via existing recovery notice and export. No cloud or server storage. Device storage usage/quota and persistence permission are best-effort browser APIs; unsupported/denied does not prevent play. Browser persistence request only on explicit user action. Service worker fingerprinted asset integrity and safe update gates remain intact; Native QA is intentionally not a production service worker build.

## CPU optimization
Canonical chunk corners calculated once; culling short-circuits only after all four exclusion tests have been disproved. Arbitrary noncanonical chunks still compute fresh bounds. Projection caches camera pitch basis and yaw; annual ambient cohort day/night arrays rebuild when year changes, including time rewind. Per-frame actor coordinates are still computed continuously. Exterior render interval is disabled while phone modal is open, retains normal cadence after close; management modal HUD updates at 1 second instead of 250 ms unless an interior is active. No change to game simulation step, graphics quality preset, geometry, GLB or shadow settings. Existing adaptive resolution, frame pacing, chunk LRU and Three.js rig cache unchanged. No hardware FPS/RAM/VRAM claims.

`node scripts/benchmark-digital.mjs /path/to/extracted-V2.13.0`: 7 alternating samples, 3 warmups; 184,320 culling checks per sample, 5,000 ambient samples. In QA, culling median 72.70 → 35.90 ms; ambient median 64.28 → 39.00 ms. Exact culling across 18,432 combinations and ambient snapshot equality at representative year/time points. Results hardware/runtime dependent, not frame time or FPS.
