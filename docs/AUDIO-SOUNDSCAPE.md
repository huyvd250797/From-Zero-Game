# V1.10.0 — Audio & Soundscape

## Player controls
Open Cài đặt → Âm thanh & nhạc nền. First trusted tap/click/key enables Web Audio, subject to browser policy. If silent use Bật / nghe thử; check device media volume and output. A reset applies default audio values only. The six groups (environment, weather, vehicles, activities, music, UI) and master use separate gain nodes. Stereo toggle disables directional pan, not distance attenuation. Preferences use `fromzero.audio.v1` in localStorage; character save schema is unchanged. Exported game JSON does not include device audio preferences.

## Runtime
`src/audio.js` is renderer-independent and uses Web Audio API (AudioContext or webkitAudioContext). A compressor protects the master output; four filtered noise loops share one generated buffer, two oscillators synthesize vehicle motor tones. Procedural one-shots use enveloped noise or oscillator tones. At most 20 transient voices coexist; finished nodes disconnect. Original slow synthesized chord motif has day/night variations. All sounds are generated by code at runtime, not recordings, not external services. No microphone access or network requests. Native build fingerprint and production precache automatically include the module.

The main loop updates the audio scene at most 10 times per second when unlocked. Outdoors: day/night, district, road proximity and game weather determine bed levels. Nearby moving traffic and NPC conversation use distance falloff and camera-relative stereo panning. Player steps are driven by distance between sampled positions with a discontinuity guard. Vehicle pitch follows actual driving speed; EV tone differs and bicycle has a mechanical cue instead of engine noise. Inside: no outdoor traffic bed, venue-dependent room hum and attenuated rain. Activity scenes trigger synthetic sound cues matching mode (drink, cooking, typing, reading, sleeping, etc.). Title plays quiet music; gameplay pause and ordinary menus silence world audio. Activity/room animation scenes can continue their own sound when not globally paused. UI cues remain available in menus. Weather sound follows selected game weather even if visual effects are disabled; mute the Weather channel separately.

Audio is suspended on pagehide/hidden, and resumes if browser allows. If a browser blocks unlock, retry through a gesture; unsupported audio is optional. Audio state is ephemeral and cannot award items, progress time or affect simulation. No save/DB migration. Headless tests do not establish perceived sound quality or physical loudspeaker behavior.
