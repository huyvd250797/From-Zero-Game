# V2.5.0 — Greater An Lac City
Baseline: V2.4.0 user-supplied source. No Third-Person; no SQL or backend.

## World and content
384×384 world (147456 square world units vs 36864). Preserve old origin and old 192×192 region, add east and south districts. Eight new districts: Đông An Bình, Tân Trung tâm, Đại học An Bình (district name; training center is vocational), Khu công nghiệp Tân Phát, Nam An Lạc, Phú An, An Bình Riverside, Tân Phú. 229 lots, 206 solid buildings, 60 interactive sites. River x=194..202 with east-west crossings on 12 road axes; 24 road axes total, 144 intersections, 144 chunks. The river is a visual water strip and blocked collision region outside bridge corridors; no boating, hydraulic simulation, elevation or new physics. Old street segments are extended by the existing road geometry generator; do not promise identical landscape at the previous map boundary.

All old plot, node, district, road, employer, property, course and action records retain exact values. City dimensions and shop lists are intentionally expanded. Master Data 3.0.0, 60 catalogs, 988 entries. 19 added employers reuse existing jobs; 32 local actions use existing work/visit/rest rules; six added properties reuse existing property types; two added courses reuse curriculum and requirements. All expansion activities require presence. New stores share existing items; no separate inventory or new goods. New sites open UI modules where supported; they do not have individually authored public 3D interiors. NPC count and NPC schedules remain 25 and unchanged; new neighborhoods will be sparsely populated until V2.6.0.

## Navigation and rendering
Indexed obstacle buckets and shared segment sweep prevent crossing water or buildings. A* reuses fixed-size typed arrays and generation stamps, retains bounded route cache (128). All 3540 ordered distinct destination pairs checked for raw grid and smoothed route reachability. Existing roadRoute handles bridge roads and bus/taxi; 14 stops. No new vehicle AI or traffic rules. Traffic has a maximum of 48 candidate vehicles on 24 axes. Camera overview fits wider city; search by accent-insensitive name, filter by district, click destination or map. Full map is independent of optional minimap. Preserve joystick, HUD, notifications and lighting behavior.

32×32 chunks (144) and 64×64 macro chunks (36); viewport selection, predictive preparation, LRU, instanced trees, stable lamps and two LODs inherited. 346 streetlights, 960 street trees. Whole-map static mesh triangles: 133118 low, 365406 high, max high chunk 11858. Whole-map ceilings scaled for fourfold area, per-chunk ceiling remains 14000. Full-map overview necessarily renders more than previous map; no promise of mobile FPS. GPU memory and all visible lamp appearance require real Three.js/device test.

## QA and deploy
561 independent tests; 551 inherited (updated expected counts/extent/budget where intentional) and 10 expansion tests. Native QA build with 84 resources verified SHA-256 and HTTP. Browser QA Chromium Canvas fallback, in-memory storage and blob module imports, desktop 1440×900/mobile 390×844; map count/search and navigation selection, minimap hidden, HUD 4 actions. 30-day survival identical across difficulties. Three.js r180 not cached (ENOTCACHED); actual production build fails strict missing dependency gate. Run npm ci, npm run build, npm run verify:release and npm run smoke:http on connected Windows/Linux machine or Vercel. Framework Other, Node 22.x, output dist. Do not publish native preview. No SQL. Export backup before upgrade; restore prior backup before rollback if save includes expanded coordinates or records. No production deploy performed.
