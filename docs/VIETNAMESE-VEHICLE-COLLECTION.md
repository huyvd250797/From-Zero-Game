# V3.18.0 — Vietnamese Vehicle Collection

Original parametric meshes inspired by named vehicles; no licensed OEM CAD, logos or manufacturer-certified dimensions. All prices, capacities, physics and maintenance costs are gameplay estimates. Six legacy purchasable vehicles remain; nine models added. Shared PBR material groups and existing mobile LOD limits retained. 360° preview uses the same projected triangle geometry on a single Canvas2D, updates only on interaction; approximate finish shading, not a PBR showroom. Number plates use stable deterministic hash suffixes, not a globally unique registration database. Named NPC pre-owned cars assigned by age/role cohort, commute expense and cash gate retained; background AI uses all nine at peak, no change to fleet budget. Existing audio profiles extended with synthetic sounds; device audible output still unverified. Save schema 1, urban layout 9. No database migration.
