# V2.6.0 — Autonomous NPC & Population
Baseline: user-uploaded V2.5.0. Orthographic city camera, 384x384, 206 buildings, 60 locations and original player rules unchanged.

## Population
65 named canonical NPCs: original 25 records byte-equivalent as JSON values, 40 new unique Vietnamese names. New NPCs live in existing houses/apartments/rooms; industrial/civic/commercial workers commute from nearby residential buildings. 14 districts have named homes; all 18 have named work/study/visit destinations. 90 background walking candidates (five per district); 18 at night in the deterministic roster. Background actors have short walkable out-and-back routes, no profile, financial state, name label or relationship interaction. They do not count as named residents. No population growth/birth/death simulation in this release.

## Persistent daily simulation
`population.js`: each resident has independent cash, earned, spent, six daily need scores (energy, hunger, hydration, social, health, stress), days worked, plan, off flag and symmetric relationship scores. Starting balances and costs are fictional, deterministic. Income from canonical monthly wage where available (daily pay accrual /22); fallback 6m monthly for working residents without matching employer; student/visitor allowance 45k/day. No actual NPC hiring/vacancy reservation, pay-day payroll or real market coupling. Costs are aggregate housing/basic food/leisure amounts; no NPC inventory or item stock mutation. At each crossed midnight settle the previous plan once; then choose routine/rest/social/save/study/supplies using need scores, personality, cash, date and health. Weekends off except service workers; health below 35 permits leave. Work/study base shift remains canonical, rest/save send residents home after shift, study chooses a suitable library, supplies chooses a suitable shop/cafe. Day-off plan omits commute to work. Needs are daily aggregate state, not minute-by-minute physiology. Plans do not change mid-day. A* routes use existing collision/speed rules; no autonomous vehicle AI in this release. Social links form bounded symmetric adjacent-neighbor graph (51 undirected edges); daily social scores model estimated exposure, not proof of exact meetings. Existing player relationship and family rules independent.

## UI and performance
Social screen → Dân cư: summary per district, current work/study/visit counts, planned working count, five ambient candidates per district. People tab has district filter and accent-insensitive search. Resident profile shows daily plan, needs, cumulative income/expenses, cash and neighbor links; no routine NPC journal or toast. Diagnostics JSON includes named/ambient presentation count. All 65 canonical positions are sampled analytically; expensive separation and animation updates only for visible region + margin or near player. Offscreen presentation entries dropped, renderer rigs culled; ambient always low LOD, caps 8/16/24/32 by preset (Eco 8). Actual GPU frame time not measured. Background routes can traverse walkable open space, not a dedicated pedestrian sidewalk network; no collision between ambient actors and other actors. No extra dependency or backend.

## Save / QA
Master Data 3.1.0, 60 catalogs, 1028 records; only NPC_Master and schema version changed. Save schema 1 adds population object validated by known IDs, finite integer bounds, nonnegative money and symmetric links. Legacy save without population starts simulation at current saved day, no retroactive NPC transactions. New save with new NPC contacts may fail on rollback; restore pre-upgrade JSON. 571 unit tests (10 new), 195 base commute legs, 30 days ×65 resident schedules checked, 90 background routes sampled. Desktop/Mobile Chromium QA uses Canvas fallback with Blob imports and mocked localStorage. Native QA 85 resources; production Three.js dependency not cached (`ENOTCACHED`). No physical device/GPU acceptance. Deploy via npm ci / npm run build, dist, Node 22.x, no SQL or env. Do not deploy native preview. Backup before upgrade.
