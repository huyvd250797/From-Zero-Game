# V2.4.0 — Advanced Lighting & Atmosphere
Baseline: uploaded V2.3.0 City Graphics 3.0. Visual-only upgrade, top-down orthographic camera, 192×192 city, canonical plots and 82 streetlights unchanged.

## Implementation
- `atmosphere-detail.js`: shared deterministic visual helpers: WeatherTransition (smoothstep 1.6 s, dt capped .25 s, retarget from current), sky palette and 1×32 RGBA texture, window intensity, fog distances, cloud footprints, soft radial maps, wet-road response, storm flash and thunder scheduling, per-quality budgets. Automatic climate uses the prior 180 game-minute period and 24-minute blend, persistent wetness unchanged. Manual transitions do not modify the climate schedule or the save.
- `weather.js`: atmospheric palette, overcast attenuation, hemisphere sky/ground fill, ACES exposure, subtle warm sunrise/sunset, storm factor. Rain overlay lower opacity, preset DPR limit, optional soft cloud overlay on non-Three renderers. Lightning modifies ambient/exposure/background, not physical electrical strikes. Flash envelope up to .42, .8 seconds, at most one deterministic pulse per 24 visual seconds. Flash suppressed when reduced motion, preference off, paused, or simSpeed != 1. Delayed thunder uses procedural noise on the existing weather gain bus, one cue per slot at normal speed. Not a new audio asset. Weather toggle disables these effects; base nighttime lighting retained.
- `three-bridge.js`: optional group 7 recognizes canonical facade glass RGB and its existing directional tint factors. Preserves indices/positions/count, and legacy seven-group conversion remains default. ThreeRenderer uses extra material only for city/bench static meshes; generic glass no longer emits warm light. 2,064 low and 6,446 high window triangles tagged across all 36 chunks, not number of individual windows. Adds up to one material group per chunk with windows (33 across full city). Intensity follows time, late-night dimming; no per-house occupancy simulation.
- `three-weather.js`: sky DataTexture updated only on changed quantized bytes. Instanced cloud shadow plane footprints (soft dark map), instanced road-aligned reflection planes (soft additive highlights), existing instanced lamp bulbs and glow for every visible lamp. Wetness affects asphalt roughness .96→.22, brightness 1→.71; wet reflections are approximations, not SSR, planar mirror or GI. Reflection positions derived from road edge and stay within road width. Clouds are ground shadow footprints, not volumetric sky clouds. Dispose all new textures, meshes, geometry/materials and detach background. Fog adapted to orthographic projected world span. Directional PCF shadow radius and strength vary by overcast and preset; retain texel snapping and quantized extent. Actual PCF result and GPU cost need production validation.
- `renderer.js`, `renderer-next.js`: Canvas gradient and window color approximation; Native WebGL uses atmospheric palette, window emissive approximation and legacy lamp geometry. Both support bounded animated puddle rings; non-Three weather overlay shows soft cloud haze. Canvas painter depth limitations remain; Three effects not fully reproduced.
- `main.js`: lightning preference under Settings, shared visual state, diagnostics of window triangles/clouds/reflections in Three. Existing renderer fallback and PWA checks preserved. No dependency, network or database changes.

Eco limits weather to Medium. Glow and bulb instances never capped below viewport selection; max 82 each and reflection instances up to same max. Additional cloud/reflection maps 64×64 RGBA each; sky 1×32. Rain overlay canvas DPR 1–1.25. Cloud matrices refreshed at 8/10/15/20 Hz. No point/spot shadows. Additional transparent batches may increase GPU overdraw; budgets are not measured FPS.
