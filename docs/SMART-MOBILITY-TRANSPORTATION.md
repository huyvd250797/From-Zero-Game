# V2.7.0 — Smart Mobility & Transportation
Baseline: uploaded V2.6.0. Master Data 3.1.0, 384×384 map, 60 interactive locations and 65 named NPCs unchanged. Save schema 1; no database, dependencies or environment variables added.

## Public transport
- AL01 Trung tâm – Tây An Lạc: shop, office, mall, market, school, hospital. 12-minute headway, 40-minute end-to-end in each direction.
- AL02 Trung tâm – Đông An Bình: mall, east_market, tech_hub, new_factory, east_school, hospital. 15-minute headway, 43 minutes.
- AL03 Nam An Lạc – Tân Phú: school, south_farm, phuan_market, river_park, tanphu_market, new_factory. 15-minute headway, 50 minutes.
- Both directions depart terminals at 06:00 to the last headway-aligned departure not later than 22:00. Intermediate stops can be served later; next-day service computed correctly. 1-minute intermediate dwell; each segment duration = ceil(road length / nominal 14 world units per game minute), minimum 1. Timetable is authored in code, not new canonical catalogs. Each boarding costs base 7,000 VND adjusted by existing economic index. Earliest-arrival graph considers three nearest access and egress stops and a 90-minute maximum wait per boarding. A bus may be unavailable where walk-only arrival dominates or service is closed; not an exhaustive all-stop, lowest-price optimizer. All routes validated against world obstacles and river crossings.
- Taxi quote from walkable outdoor position to destination door: base 12,000 + 120 × route length, adjusted by existing fuel price index. Pickup wait 3 game minutes, 6 in peak periods. Nominal speed 28 multiplied by traffic factor. Taxi appears after wait, not a dispatched vehicle with visible inbound route. No dynamic driver availability.
- Destination chooser compares direct walk, available parked owned vehicle, bus and taxi. Public trip samples path against game clock; times and prices shown before confirmation, and same clock drives scheduled bus visuals. Intermediate walk, wait, ride, transfer and final walk use continuous validated segments; the bus associated with the passenger is suppressed from independent rendering to avoid duplicate bus. Simulation speedup also speeds public journeys, unlike manual movement. Fare charged upfront, no refund on cancellation. Session-only journey is cleared on reload; saved position and fare remain. No physical collision between background traffic and public buses. Existing legacy transitQuote retained for compatibility, actual UI uses publicJourney.

## Resident mobility and parking
- 50 of 65 named residents have deterministic pre-owned mobility assets (19 bicycles, 26 motorbikes, 5 cars); 15 have none. No simulated purchase or asset transfer. Default initial daily plan: 28 walk, 18 bike, 16 motorbike, 3 car; daily mode changes by distance, cash, health and save plan. Mode held for the entire day. The schedule path remains canonical for interaction and rendering. Vehicle movement uses validated road routing; cost 8/55/150 VND per world unit for bike/motorbike/car (game balance, not real fares), included in the daily NPC ledger. Optional transportSpent is validated and initialized lazily for old saves; player balance unaffected. NPCs do not currently ride the scheduled bus or taxi. Parked ownership visuals are derived from stationary schedule anchors, prioritizing free nearby marked bays, else nearby validated outdoor spots; no persistent NPC vehicle parking/retrieval trajectories.
- Player marked-bay availability uses vehicle dimensions and combined resident/player parked positions. On arrival, recheck and seek another free bay if occupied. No new parking fees, fines or collisions; manual roadside parking retained. Private NPC vehicles cannot be mounted by player. NPC interactions only when not riding. 
- Existing A* remains fallback. Sidewalk preference tries road-margin connections, validates all segments, limits detour to 35% above direct route. Not a fully separate pedestrian graph. Peak 07:00–09:00 and 16:30–19:00; automatic player travel speed multiplier 0.72, normal day 0.90, night 1. Aligned road segments observe red/amber stop lines with safe position limit; inside-junction exit and manual control retained. No dynamic queue length/collision-aware lane changes; background traffic remains deterministic, not a full agent traffic simulation. Public bus timetable fixed; NPC private trips use fixed per-mode speed.

## Performance
- Scheduled bus visible budgets Low/Medium/High/Ultra 4/8/12/16, named resident vehicle budgets 8/12/18/24 (Eco 8). Moving vehicles prioritized. Background traffic and 90 ambient walkers keep existing budgets. Near/far culling, geometry LOD and stable identities preserved. Resident parking snapshot cached per game minute and player parked positions; public road/sidewalk path caches each bounded at 180 entries. Rendering CPU time and device GPU FPS require production QA. No claims of real-world traffic simulation.
