# V1.2.0 — Immersive City

## Architecture and scope
The 79 canonical sites (62 solid buildings, 17 open plots) are still read from `world.js`. `city-architecture.js` creates deterministic, shared triangle geometry. Twelve canonical styles: retail, rowhouse, park, tower, civic, medical, industrial, school, farm, sport, parking and house. Ten district palettes. No new simulation records, doors, collision or A* rules. An interaction entrance is still the canonical door coordinate; the visual façade is oriented toward that door. For noninteractive lots the façade uses the south default. Decorations do not add collision or interactions. Entrances keep canonical yellow markers. Flush paths link to nearby sidewalks only when a straight route is clear of buildings. Visual details may be walked through.

## Art direction
Original procedural geometry; no third-party artwork. House/rowhouse: narrow bays, warm paint, pitched terracotta roofs, terraces, balconies. Retail: glazed frontage, awnings, sign panels, café furniture. Office/apartment: curtain wall strips, apartment balconies, rooftop equipment. School/civic/medical: porticos, signage, civic pediments and flag, cross; industry: shutters, corrugated gables. Park: polygon fountain, rounded and palm-like trees, benches, shrubs, flowers; garden/farm rows, football markings, goals, parking stalls. Street edge: curbs, lane-edge stripes, paving, lamps, bins. 21 named sign texts built from original geometric glyphs with approximate Vietnamese diacritics; full canonical labels remain HTML in game. No separate collision or lit lamp sources. No real texture images, imported full building GLBs, dynamic weather or interiors in this release.

## Rendering and budgets
Same V1.1.0 WebGL 2 adapter, WebGL 1 and Canvas fallback. Material heuristic extended for tall glazed panels. Shared 36 chunks; high LOD adds glyphs, window frames, balusters, roof lines, paving, vegetation. Low LOD simplifies windows/railings, omits glyphs and fine detail, reduces vegetation. Canvas Low/Medium always use low LOD; High/Ultra allow high LOD at near zoom. Conservative culling includes approaches beyond plot. Measured static triangle counts: 41,762 low, 123,570 high (previous 15,576 / 32,794). This is a geometry count, not measured frame performance. High LOD increases CPU/GPU/memory load; use Low if needed. Existing GLB bench sample remains, no new external dependencies.

## Acceptance and verification
11 new tests cover deterministic geometry, LOD budget, façade orientation, palettes, signs, door/plot exclusion, entrance paths, road details, material, and save/world invariants. Full release checks via `npm run release:check`. Isolated GLES harness uses actual shared vertex geometry and the scene/depth shaders; day/night in three locations. Chromium module-build fallback desktop/mobile with mock storage; not full WebGL 2/browser PWA testing. No physical-device FPS, VRAM, PWA installation/offline or Vercel deployment verified. Back up save and verify actual WebGL 2 in Settings after deploy. Use the same origin for existing data. Check interactions at doors (not decorative props), camera zoom and Low/High. Keep V1.1.0 for rollback.
