# V2.3.0 — City Graphics 3.0
Baseline: uploaded V2.2.0. Keep orthographic camera and all game rules. No new dependencies, database, SQL, Master Data, game state fields, collision or road topology. 192×192 world; 79 plots (62 solid structures, 17 open plots), 28 interaction destinations, 36 chunks, 25 NPCs.

## Scope and implementation
- `city-design.js`: 21 landmark overrides; 27 visual profiles derived across existing solid/open plots. Existing 12 canonical styles preserved. `city-architecture.js`: roof water tanks on select rowhouses, balcony planters, vents and AC units, storefront display bands, mall/market roof and façade variations, office mullions, apartment planting, loading door framing, bank pilasters, school shades. Selected landmark rooftop signs and existing front signs use geometric Vietnamese glyphs; letter detail is High LOD only. Roofs remain within existing culling height envelope. Models are procedural stylized geometry, not new architectural GLB assets. Exterior only; interior/business functionality untouched.
- Roads: flat asphalt surfaces split at junctions to avoid overlapping coplanar road planes. Flat two-triangle lane paint/crosswalk/tile rectangles instead of five-sided boxes. Crosswalks and stop lines at all 36 intersections in both LODs. Sidewalk tiles, drain grates, generic direction signposts, improved bench and planter geometry; props are visual-only, not collision entities or new transport stops. Existing canonical routes and widths remain unchanged.
- Vegetation: stable 240 roadside tree positions in both LODs (previous 120); existing instancing types retained. Crown colors and park planting improved. All 82 lamp coordinates and existing viewport lighting mechanism unchanged. Existing LOD hysteresis, predictive preparation, shadow stabilization, shared material groups and 128px texture resolution retained. Refined texture patterns for asphalt, pavement, wood, vegetation, concrete. No dedicated PBR material maps or new weather effects.
- Geometry counts from `makeChunk` on all 36 chunks, including street trees before extracting into instancing: Low 36,962 → 40,148 (+8.62%); High 123,570 → 116,108 (-6.04%). Peak per chunk Low 1,958 → 2,074; High 11,512 → 11,858. Existing bounds 50k/140k total and 14k per chunk preserved. Counts not FPS or actual per-frame GPU draw calls. Denser street trees may cost more GPU on Low and on densely visible scenes; no measured device speedup. No changes to actor rig/GLB assets.

## QA and limitations
- 540 independent unit tests: 531 inherited, 9 new, 0 failed. Tests cover profiles, road segment splitting, flat paint, intersections, LOD-stable trees and lamps, deterministic geometry bounds, triangle budgets, textures, route preservation. Native preview: 83 fingerprinted resources with SHA-256 and HTTP check. 30-day survival identical: easy 5,180,000; normal 3,050,000; hard 705,000; health 100 all. All 61 Master Data files byte-identical to baseline.
- Chromium Desktop 1440×900 and mobile 390×844 using Blob module import and mocked localStorage, Canvas fallback: continue game, weekday, 4 quick actions, default hidden minimap, settings/version, no uncaught page errors in those flows. Software mesh previews use source triangles, same orthographic projection, offline depth rasterizer, no actual Three.js material/shadow/texture render; not screenshots of production gameplay. Canvas fallback's painter sorting can show triangular overlap artifacts, not fixed in this release. This limitation differs from Three.js depth-buffer rendering, which remains unverified here.
- `npm ci --offline` returns ENOTCACHED for Three 0.180.0. Production build fails explicitly at missing dependency. No real Three integration or hardware FPS, visual quality, heat, VRAM, Safari/PWA offline verification. Deploy production only with `npm ci` and `npm run build`, output `dist`, Node 22.x, no env. Never publish `dist-native-preview`. Export save first. Inspect near/far city, daytime/nighttime, zoom/rotate, 82-lamp coverage, route & parking, camera movement and p95 on real PC/iPhone. Verify PWA update/offline and existing save after deploy. No GitHub push/Vercel deploy performed here.
