# From Zero V1.12.0 — Visual Performance & Polish

Baseline: supplied V1.11.0 Game UI & HUD 2.0. Three.js 0.180.0 unchanged, schema 1 and canonical master data V2.9.0 unchanged. Release candidate for V2.0.0; not a production GPU acceptance certificate.

## Renderer and budgets
- Direct typed-array mesh conversion preserves original vertices, normal orientation, index winding, group order and color values. Untextured dynamic geometry skips UV allocation. Renderer skips the redundant NPC geometry loop when skeletal actors are rendered separately; parked vehicles outside a padded screen boundary are not generated.
- At low LOD and zoom below 0.78, 36 canonical 32-unit chunks can be grouped into nine 64-unit batches. Generate each original chunk separately to preserve the geometry and trees exactly; merge buffers and instance trees by type. Near camera use individual chunks. Tradeoff: a partially visible macro batch can include some unseen geometry. Limit cache entries to 18 (Low or eco), 28 (Medium), 44 (High/Ultra), raised only if the visible set needs more. Evict inactive entries only and dispose GPU resources. Not asynchronous world streaming; whole world data remains available, meshes allocated as visible.
- Three.js and native rendering have internal pixel caps (Low 1M, Medium 1.8M, High 3M, Ultra 5M); eco 0.9M. Legacy uses Low/Medium budgets. Limits apply independently of adaptive resolution; small differences from raster rounding possible. CSS HUD and camera picking remain unchanged. Adaptive resolution handles sustained slow frames up to 1 second (each sample capped at 500 ms; ignores larger suspended gaps), hysteresis retained.
- Optional `eco` preference caps render at 30 FPS, shadow map at 1024, weather budget at Medium, and pixels at 0.9M; does not change simulation speed. Default remains existing preset. Three.js shadow pass 100/100/67/50 ms for Low/Medium/High/Ultra, refreshed earlier on camera displacement, zoom or visible set change; eco uses Medium cadence. This can cause slightly less fluid moving shadows. Daytime local lights hidden, no unnecessary shader light contributions. Composer only rebuilt when post-processing settings change.
- NPC clip definitions shared by four age stages. Visible actors animate at their existing rate, offscreen rigs hidden and retained up to six seconds before disposal; player rig removed immediately when not required. Paused NPC time scale zero. Crossfade releases completed old actions. No new animations or changes to NPC schedules. Traffic lane constants precomputed and axis phase calculated once per axis. No change to traffic simulation output.
- Labels precompute place priority and distance once per render and skip offscreen updates; preserve HUD and browser zoom guard.

## PWA and storage
- Service Worker precaches and verifies SHA-256 as before. Failed new install cleans newly created incomplete cache, retains current cache. On activation retain at most one older fingerprinted cache with a shell. Only previous fingerprinted asset URLs may be served from that cache; navigation always uses current shell, current assets stay verified. Cache repair still returns verified response when quota prevents cache write. Old cache consumes additional storage, bounded to one previous release. An old tab more than one version behind may need reload. Updated status reports failed downloads even with an active previous worker. Existing save primary/backup/checkpoint and conflict protections unchanged.

## Measured evidence (Node.js 22.16.0, same environment, not physical GPU)
`node scripts/benchmark-polish.mjs /path/to/extracted-V1.11.0` runs the same dynamic triangle streams through both conversion functions, five measured batches of 120 calls after warmup; verifies equality of 72 static LOD/chunk conversions and 2000 traffic snapshots. First run medians: 405.342 ms old, 233.995 ms new; subsequent run 407.129 ms old, 254.498 ms new (37–42% less CPU conversion time). No claim about whole-game FPS. Full city LOD-low static material groups 222 -> 58; tree instance type groups 76 -> 27, static triangles excluding separately instanced trees 38888. Material-group counts are theoretical draw submissions before culling/shadow/post passes; real draw calls may differ. No real GPU VRAM or thermal measurements.
