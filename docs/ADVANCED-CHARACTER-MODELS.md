# V2.2.0 — Advanced Character Models

## Assets and runtime
Four original GLB 2.0 files in `src/assets/characters/` are generated deterministically by `node scripts/generate-character-glb.mjs`. They contain a skinned mesh, 13 named joints, inverse bind matrices, vertex colors, normals, indices and skin attributes; they do not contain baked animation tracks. Three.js GLTFLoader loads the four local assets, SkeletonUtils clones the rig; custom appearance replaces geometry with the same generator used for the templates, preserving joint names and transforms. The 19 existing clips are generated in JS. On load failure, use procedural rig. The fixed-size template cache is shared for the page lifetime; per-actor geometries and skeletons are disposed, CPU custom geometry cache bounded to 16 entries, previous actor cache and LOD hysteresis retained. CPU/Canvas preview uses the same shape generator but not GLTFLoader or smooth normals. Rigid joint weights (not blended deformation); stylized original meshes, no third-party licensed art or facial morphs. No full garment physics.

## NPCs
All NPC IDs unchanged except new NPC_SAO. Three- and four-word names stored once in canonical `NPC_Master.json`, never randomly reassigned on load. Sao is a fictional student, initial age 17 vs player 18; occupation and home/school/leisure chosen from existing valid locations. Existing adult relationship gate unchanged. Normal 1x travel rate 1.55–1.82 world units/second for current population; duration derived from path length. Short morning trips arrive before shift and wait; long trips start earlier. No changed work shift start/end. At high game speed, movement accelerates as simulation does. NPC interaction, world positions and labels share canonical schedule; leisure walk presentation stays bounded. Family/partner home remains dynamic. NPC context wardrobe uses existing work/study status. Player selects clothes in Appearance. NPC profile renders model preview and readable schedule. No new gameplay economics.
